# 🚀 Gestor de Proyectos y Equipos (Simulacro de Nube)

Aplicación web relacional desarrollada con Django para la creación de proyectos, asignación de tareas y administración de equipos de trabajo. Este proyecto fue construido y configurado como parte de un simulacro práctico para evaluar habilidades de despliegue de servicios en la nube.

## 🛠️ Tecnologías Utilizadas
* **Backend:** Python 3, Django
* **Frontend:** HTML5, CSS3, Bootstrap 5
* **Base de Datos:** SQLite (Desarrollo local) / PostgreSQL (Producción)
* **Despliegue:** Render, Gunicorn, Whitenoise

## ✨ Características Principales
* **Gestión de Proyectos:** Operaciones CRUD (Crear, Leer, Actualizar, Eliminar) para administrar proyectos generales.
* **Control de Tareas:** Creación de tareas específicas vinculadas a proyectos, con seguimiento de estados (Pendiente, En Progreso, Completada).
* **Administración de Equipos:** Creación de grupos de trabajo y registro de integrantes.
* **Asignación de Responsabilidades:** Delegación de tareas directamente a los miembros de los equipos registrados mediante un modelo relacional de base de datos.
* **Interfaz Responsiva:** Diseño limpio y adaptable a dispositivos móviles.
